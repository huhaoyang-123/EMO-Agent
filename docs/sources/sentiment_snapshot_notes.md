## 文件

- 本说明随历史情绪快照迁入；以下 CSV 位于 `data/input/sentiment/`。浏览版工作簿未迁入，避免重复维护。
- `931723成分股分时明细.csv`：完整的 83,653 条公司分时记录，含原始计数、历史成分有效期、推定时段及源 ZIP / XLSX / Excel 行号；六位 `Scode` 要按文本读取。
- `931723行业统计日.csv`、`931723行业分时.csv`：基于已观测成分股记录的行业汇总。
- `931723成分股覆盖.csv`、`931723缺失时段.csv`：逐只证券覆盖与未见的预期公司时段；缺失不填零。
- `931723源文件清单.csv`、`summary.json`：输入清单、校验信息及提取规模。

## 提取口径

从 4 个 CNRDS GUBA 原始 ZIP 中扫描 24 个 XLSX，按源统计日期 `Date` 与 931723 历史成分有效期 `[in_date, out_date)` 匹配。历史成分代码共 64 个；有效期内保留 83,653 条公司分时记录、3,044,795 篇已统计帖子。日期从 2023-10-31 到 2026-06-30。仅用当前历史成分表可以支持的时间范围；不回推发布前成分。

`net_sentiment = (Pospostnum - Negpostnum) / Tpostnum`；分母为零时留空。`directional_sentiment = (Pospostnum - Negpostnum) / (Pospostnum + Negpostnum)`，分母为零时留空。行业净情绪用行业正、负面帖子合计计算；`equal_weight_sentiment` 是当天已观测公司的净情绪简单平均，不是指数正式权重。行业日度表包含非交易日；做指数日收益对齐时请筛选 `is_trade_date=1`，并按研究问题确定特征截止时点。

`Date` 是源数据统计标签。源时段如 `15:00-9:00` 跨越前一日；`interval_start` 和 `interval_end` 依据源字段说明推定，不是逐帖真实时间。源包只有汇总计数，没有帖子正文、逐帖时间和情绪标注依据；历史计数在当时是否已经可见、后续是否修订，尚未核实。因此这些文件可用于描述性探索，不能直接据此声称事件归因、无泄漏预测或策略表现。

## 校验结果

公司、日期、时段键未发现重复；已观测行的 `Tpostnum` 与正、负、中性帖合计一致。公司明细按日期聚合后，与行业日度表的帖子量逐日一致。645 个交易日中，473 天全部当日成分至少有一条记录；117 天所有预期公司时段齐全。其余缺口详见覆盖与缺失文件。
