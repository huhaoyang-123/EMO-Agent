# 模型数学定义、实际参数与下一步

更新：2026-11-13；对应正式实验 baseline_v1，未开展第二轮调参。全部为 L2 正则逻辑回归：行情/行情＋情绪 × 1日/5日，共四个独立模型。

## 目标与时间

令 P_t 为第 t 个交易日收盘点位，h∈{1,5}。标签 y_(t,h)=1[P_(t+h)>P_t]。收平/下跌为0；未来价格缺失留空。概率是第 h 个交易日收盘高于当日的概率，不是连续上涨或区间内曾上涨概率。

每天16:00（Asia/Shanghai）做预测。每个源情绪时段按 interval_end 归到其结束后的首个交易日16:00，周五晚间/周末/假期均不会提前使用。历史实际发布时间未验证，因此仍属统计区间对齐的探索。

## 行情输入：6个变量

令 r_t=P_t/P_(t-1)-1，A_t 为当日成交额。

- R_(t,k)=P_t/P_(t-k)-1，k=1,5,20。
- V_(t,k)=sqrt(sum_(j=0)^(k-1)(r_(t-j)-mean_k(r))²/(k-1))，k=5,20。
- Q_t=A_t/[sum_(j=1)^20 A_(t-j)/20]-1。

X^M_t=[R1,R5,R20,V5,V20,Q]。只用发布后行情起算；前20个预测日用于预热。

## 情绪/质量输入：7个变量

在当前预测窗口内，i公司正/负/总帖记P_i^+/P_i^-/T_i。只累计已观测记录。O_t为总帖数>0的已观测公司集合。

- 帖子量加权净情绪 S_t=(sum_i P_i^+ - sum_i P_i^-)/sum_i T_i。
- 公司等权 E_t=mean_(i∈O_t)[(P_i^+-P_i^-)/T_i]。
- 情绪变化 ΔS_t=S_t - sum_(j=1)^5 S_(t-j)/5。
- 每观测公司时段帖子强度 q_t=sum_i T_i / observed_slots_t。
- 热度 H_t=log(1+q_t)-log(1+sum_(j=1)^20 q_(t-j)/20)。归一化有助于降低周末窗口较长的机械影响，不等于完全消除窗口差异。
- G_t=observed_companies/expected_companies。
- K_t=observed_slots/expected_slots。
- D_t=1[S_t缺失]。

Z_t=[S,E,ΔS,H,G,K,D]，实际增加7列，H中的q是中间量。窗口expected_companies按源Date历史成员的并集定义，跨调整窗口不一定恰好50家。缺失不作中性；无有效分母留空。

X^(M+S)_t=[X^M_t,Z_t]，共13列。D在本次有效样本中恒为0，系数为0。基础管线还支持按训练数据发现的缺失列添加指示，本次最终模型的实际维度为6/13。

## 标准化与概率公式

缺失先由训练集该列中位数填补，再按训练集均值μ_j与标准差s_j计算 z_(t,j)=(x_(t,j)-μ_j)/s_j。StandardScaler用总体标准差（分母n）；恒定列的scale设为1。验证/测试沿用训练参数。

行情模型：p^M_(t,h)=σ(b^M_h + (β^M_h)^T z^M_t)。

行情＋情绪：p^(M+S)_(t,h)=σ(b^(M+S)_h + (β^(M+S)_h)^T z^M_t + γ_h^T z^S_t)。

σ(u)=1/(1+exp(-u))。不同期限和输入组合独立估计参数；联合模型里的行情系数也重新训练。p≥0.5判上涨，否则判不涨。

训练目标（无样本/类别加权）：

L(b,w)=(1/n)sum_t[-y_t log p_t-(1-y_t)log(1-p_t)] + ||w||²/(2nC)。

截距不惩罚；L2限制系数大小，C越小收缩越强。求解器lbfgs，l1_ratio=0，max_iter=3000，tol=1e-7。C候选0.01、0.1、1、10，按2025验证集Brier最小选择，四个模型均选0.01。这仅是预先给定候选集内的选择，不是最优性证明。

对应实现的数学定义：[scikit-learn逻辑回归](https://scikit-learn.org/stable/modules/linear_model.html#logistic-regression)。

## 评价

Accuracy=mean(1[predicted_t=y_t])。

BalancedAccuracy=(TP/(TP+FN)+TN/(TN+FP))/2，分别衡量上涨和不涨的识别。

Brier=mean((p_t-y_t)²)，越低越好；比较概率本身而不只看0.5两边。参照模型固定输出训练期上涨比例，两个期限最终比例分别50.7874%和59.5238%，所以方向均始终猜涨。

[Brier定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.brier_score_loss.html)。

## 发现与问题

详见 baseline_v1.md。1日情绪只多猜对1天；5日方向完全一致且115/116天都猜涨。概率误差小幅改善，但描述性区块区间跨零；验证集情绪模型Brier反而更差。当前证据不支持稳定情绪增益。

1日行情＋情绪概率在42.95%—57.00%，多数靠近0.5；5日在49.82%—68.35%，多数高于0.5。5日最终训练上涨比例59.52%，正截距与弱特征信号共同导致上涨倾向；这属于可观察行为，不代表已找到唯一成因。

覆盖率在联合模型中也有非零系数，所以行情/联合模型的差异同时包含情绪和数据质量信息。需单独消融才能归因。当前只有一种时间切分和较少样本，5日标签重叠，模型仅线性作用于对数胜算，没有交互或非线性。历史时间可得性仍需核实。

## 下一步顺序（建议，尚未执行）

1. 保留baseline_v1。用2023—2025做多个按时间向前的验证窗口，所有边界过滤未成熟标签；2026上半年已查看，后续不能反复当作未见最终测试。
2. 公平比较：行情；行情＋覆盖/缺失；行情＋覆盖/缺失＋情绪。分别检查净情绪、变化、热度的贡献，区分质量指标与情绪内容。所有比较用相同日期。
3. 验证1/2日滞后、3/5日平滑、窗口长度控制与有限的行情×情绪交互，只在训练/验证选择。核查/记录真实数据到达时间；增加之后的新样本作为新最终测试。
4. 概率评价继续用Brier/校准，方向评价同时看平衡准确率。若为特定使用目的调整阈值，阈值只由验证数据选，不能仅凭测试上涨比例设定；报告覆盖和各类识别，不能用阈值掩盖无概率增益。
5. 如滚动验证显示稳定非线性需求，再增加一个受限复杂度的树模型对照；当前不直接跳到大量复杂模型。稳定流程之后再接每日更新Agent。
