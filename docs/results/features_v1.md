# 阶段5：情绪表达、时滞、自变量选择与模型复杂度

2026-11-17；Issue #9；实验features_v1。结论：在固定的25组候选和四季度检验中，过去验证期选出的情绪变量未在下一季度产生增益；受限树模型也没有形成总体优势。尚未找到稳定起效时点。不是证明所有情绪表达/所有非线性模型都无效。

## 实验口径

延续931723、每日16:00、1/5交易日收盘上涨标签。只用2025四季度向前评价；季度尾部跨界标签剔除，共239/223日。2026不再评分。历史2025已用于开发，本轮仍是历史诊断，不是新的独立最终测试。

6个行情变量保留作共同基线；控制模型另加入公司/时段覆盖率、情绪缺失标志和window_hours。window_hours为预测截止时间减窗口最早统计起点，是窗口跨度代理，不等同于精确公司小时暴露量。

情绪候选五组：净情绪、公司等权净情绪、情绪变化、热度、净情绪+热度。每组五种表达：当前值、滞后1交易日、滞后2交易日、含当前的3交易日均值、含当前的5交易日均值，共25组，另含不选情绪。平滑是交易日窗口，不是日历日。

### 自变量选择规则

1. 只在内层训练期检查常数/空列；候选与控制变量或已保留候选绝对Pearson相关>=0.95则剔除。外层评价期不参与筛选。
2. 每个候选最多两个情绪变量，C固定0.01。不是把25组变量全部同时放入模型，也不根据全样本p值筛选。
3. 只在过去的内层验证期计算Brier。候选必须比不含情绪的控制模型改善至少0.002；若多个候选距最佳Brier不超过0.001，优先变量更少者，再按Brier及名称确定。未达门槛则不选。
4. 冻结选中列，使用该季度开始前已成熟样本重训。外层结果只评价，不回头改选择。全部候选外层结果完整保留作诊断，不能将其中事后最佳成绩称为策略成绩。

阈值0.002和0.001为预先固定的保守工程规则，并非显著性门槛或最优值。该轮未搜索行情六变量的最优子集；覆盖/跨度控制变量也不是已证明应永久保留。所有候选在实际训练中均未触发0.95/常数剔除；这不等于没有中等相关性或信息重叠。

复杂度对照为HistGradientBoostingClassifier，50轮、深度2、最多4叶、学习率0.05、叶子至少40样本、L2=10，关闭内部随机早停划分。分别输入相同控制变量、相同选中变量，单独训练两个树模型。不另为树搜索特征或参数，因此只能判断这一有限对照的表现。

## 表达与时间的诊断证据

以下相关系数只来自各折内层训练期，范围反映四个训练窗口及两个期限成熟标签差异。相关不等于因果，也不等于控制其他变量后的独立贡献。

- 净情绪与当日收益相关0.376—0.417，与过去5日收益0.506—0.575；与未来上涨标签相关约-0.14至-0.04。数据与“情绪较强地反映近期行情”相容，但尚未证明反向因果或可交易反转效应。
- 公司等权情绪与当日收益0.271—0.340，与过去5日收益0.398—0.435；没有因滞后/平滑而获得稳定预测增益。
- 热度与时段覆盖率相关0.721—0.737，与当日/过去5日收益的相关性接近零。即使已按观测时段归一化，仍有较强覆盖关联；可能是采集口径，也可能是共同受真实参与程度影响，不能直接断定数据污染。
- 季度均值、标准差、缺失、10%/90%分位保存于quarter_distributions.csv；所有训练期相关性在train_correlations.csv。尚未执行因果检验、供应商文本标签抽查、指数真实权重聚合或实际到达时间审计。

## 自变量取舍建议

保留纯行情为研究参照，不称其有效预测产品。情绪暂列候选，不默认全纳入。当前没有证据让某个滞后或平滑表达成为固定自变量；缺失标志当前恒定，研究诊断可以保留但没有预测贡献。覆盖和窗口变量用于检查观测口径，其预测用途需单独论证。

下一阶段优先从原始公司-时段数据重构更一致的情绪观测：对相同统计时段/稳定覆盖公司做可比聚合，分析哪些公司和时段驱动热度变化，比较行情解释后的情绪残差（残差模型也只能在训练期拟合）。这比继续扩大25组搜索更有信息价值。成分股权重聚合需先核查可用历史权重；不能把当前权重回填历史。之后才考虑限定一个有机制依据的行情×情绪交互。所有这些尚未执行。

未来新日期仍需作为冻结方案后的前瞻验证。不能用本轮事后最好的候选重写已报告结果；本轮没有重新调门槛、C或树参数。
