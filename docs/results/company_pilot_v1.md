## 模型、特征与数学定义

每个期限、每个季度单独用过去数据拟合一个共享公司模型，共享斜率并加入公司截距（未知公司使用总体截距）。不是64个各自独立拟合的小模型。每季度同时训练指数的对应三组，合计72个逻辑回归模型；另保存训练期上涨频率参照概率。

令 a(i,t) 为不含现金红利再投资的可比收盘 Adjprcnd，t+h 按市场交易日历偏移：

`y(i,t,h) = 1[a(i,t+h) > a(i,t)]`。

收平为0。起点和终点要有成交和价格；期间停牌不前填。预测的是可比复权价格方向，而非名义原始收盘价。市场输入只包含t及以前；训练标签的终点必须不晚于训练截止。

`p(i,t,h) = sigmoid(b_h + u(i,h) + beta_h' z_market + gamma_h' z_attention + delta_h' z_direction)`。

数值特征中位数填补只在训练集拟合；标准化同样只用训练，按每个日期总权重1计算。模型采用L2、C=0.01、lbfgs、固定0.5分类阈值。训练每行权重 `w(i,t)=1/n_t`，全部公司合计为一个日期权重。正则化形式等价于加权负对数似然加 `||theta||²/(2C)`，公司截距也被惩罚，总体截距不惩罚。

- A行情：股票1/5/20日收益、5/20日收益标准差、相对自身过去20日成交量、换手率、流通市值；加行业1/5/20日收益和20日收益标准差。另加6个覆盖/缺失控制，共18个数值变量。
- B关注度：A加每观测小时帖量的log值及其相对自身此前20交易日均值的变化，共20个数值变量。
- C方向：B加净情绪及其相对前5交易日均值的变化，共22个数值变量。公司代码截距另外计入，不做结果驱动的公司选择。

具体表达：

`turnover_pct = 100 * Dnshrtrd * Clsprc / (1000 * Dsmvosd)`；Dsmvosd的单位是千元，价格单位元/股，因此先还原流通股数。取 `log(1+turnover_pct)`，规模取 `log(1000*Dsmvosd)`。没有把盘后成交字段额外相加；官方换手率和盘后成交口径尚未另行核验。

`volume_heat_20 = log(1+V_t) - log(1+mean(V[t-20:t-1]))`。

`rate = 总帖 / 已观测时段总小时数`；`log_post_rate = log(1+rate)`；`post_heat_20 = log_post_rate - log(1+mean(rate[t-20:t-1]))`。

`net = (正帖-负帖)/总帖`；`sentiment_change_5 = net_t - mean(net[t-5:t-1])`。无分母或历史不足保留空值。滚动窗口按公司、交易日独立计算，缺失日期不能被跨过去凑满窗口。

A已包含时段覆盖、小时覆盖、窗口小时、当期情绪缺失、热度历史缺失和方向历史缺失。B−A用于观察关注度，C−B才用于观察本轮的方向性情绪独立增量；二者都是模型对照，不是因果效应。

## 是否比指数更显著

- 2025年1日，公司方向增益−0.000030，指数−0.001744。两者差值为+0.001714且描述区间为正，表示公司受到的负面影响较小；不能把它称为公司情绪已有正增量。
- 2025年5日，公司−0.000011，指数−0.000793，两者差的区间包含零。
- 2026上半年，公司1/5日增益为−0.000014/+0.000008，对应指数为+0.000441/+0.001253；未延续公司相对优势。
- 公司与指数各自预测对象和行情控制不同，比较的是各自任务中的概率误差改善，不能直接把两种任务的准确率作为优劣证据。

两个期限均未通过预先冻结的继续门槛：2025公司增益≥0.001、区间下界>0、至少3/4季度改善；2026正增益且2/2季度改善；2025公司相对指数的增益差区间下界>0。门槛是项目管理规则，不是金融预测的普遍标准。5日2026有同向微弱改善，但不能单独支撑扩展投入。

## 本轮发现与解释边界

加入方向后，预测概率的平均绝对变化仅约0.09—0.22个百分点（四个期间×期限组合），其结果很接近B。公司净情绪的标准化系数在12个季度×期限中均为负，不能因此推断“乐观导致下跌”或可靠反向策略；样本外改善并未支持该推论。

一个可核实的限制是：固定共享斜率只能学习所有公司的平均关系，各公司潜在不同反应可能被平均。固定C和日期总权重也使模型较保守。本轮没有公司交互、个别公司挑选或额外模型搜索，故失败不能外推为所有个股表达均失败。另一方面，只有统计总量和供应商情绪标签，没有文本、作者和真实发布历史，换目标本身没有增加这类信息。

这一结果不支持在“情绪增量已经验证”的前提下立即增加更多数据源。先保留本轮作为停止扩展搜索的关口：代码、公司面板和预测接口可继续复用，但Agent不能包装成已经验证有效的预测系统。若后续重启新研究，需单独立项并明确改变哪项信息假设，而不是不断在本批历史上试到出现好结果。
