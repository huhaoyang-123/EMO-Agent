[Issue #20](https://github.com/huhaoyang-123/EMO-Agent/issues/20)，分支 `feat/20-analysis-agent-mvp`。以规范 PR #19 的提交 `dec9564` 为基线，MVP PR 的跟踪链接见 Issue。

## 实现与数据

- `configs/agent_v1.json` 与只读加载层核验指数、情绪、公司面板、宽基和广度数据。应用入口运行原有基础输入审计；加载时校验所读取的表和宽基依赖的哈希、字段、键和日期范围。未来收益和标签列从加载白名单排除。
- 提供市场概览、公司比较、同期关系、异常候选和研究证据五项工具。研究证据的来源记录在 `docs/agent_evidence.json`。情绪、指数行情与宽基分别报告可用日期，超范围提供明确的缺失说明。
- 接入 [DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)，使用 Chat Completions 和 `deepseek-flash` 非思考模式。本地校验参数和白名单，执行函数，按原始 `tool_call_id` 回送工具消息。单轮最多四次工具调用和三轮工具请求，单工具超时十五秒。最终合成时不再请求工具。详细序列和图表留在本机，LLM 接收问题、近期对话和精简结果。
- Streamlit 提供 DeepSeek 对话、结果卡片、数据审计状态与离线工具直查。CLI 新增 `agent-check`、`agent-tool` 和 `agent`。默认服务监听回环地址。密钥从本机环境变量或密码输入框读入，未将密钥加入配置样例。

## 实际验证

- 锁定依赖安装及锁文件检查通过，pytest 90 项通过，保留旧实验中的 6 条弃用警告。21 项新测试含合成数据口径、HTTP 模拟调用与消息回传、拒绝无效工具、预算及凭据相关错误处理。
- `agent-check` 通过原有 17 项基础输入审计和 MVP 派生数据检查。用 `scripts/verify_agent_mvp.py` 在 Windows 本机核验五项工具和 Streamlit 界面。示例中，2025 年第一季度 57 个指数交易日的首尾收益约 −3.05%；上半年 117 个有效同期样本中有 53 日净情绪为正而指数收益为负。2026 年 8 月有 21 个指数交易日，情绪结果为空。
- 首次真实数据检查误用开发文档结构示例的观测数，后改为从输入日线独立核对。首次 AppTest 发现缓存签名构造在迭代时修改集合，修复后真实数据验收通过。
- 模拟 API 完成三类工具调用往返以及异常路径。真实服务的鉴权、计费和中文自然语言调度尚待用本机配置的密钥验收。历史研究输入与结果只读，未训练新模型。
