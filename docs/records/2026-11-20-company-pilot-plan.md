# 公司层面有限试点：评分前方案

Issue #11；分支 feat/11-company-pilot。用户已授权个股试点，取代此前仅研究指数的范围限制。PR #10 已核实合并；本轮从 origin/main 开始。目标是检验公司层面情绪方向在量价、关注度、数据覆盖之外是否增加短期预测信息，并与行业指数的对应增量比较。

## 固定范围与样本

- 仅已有 931723 历史成分，按预测日成分有效期限制；不以未来存续/数据长度/结果挑公司，不包含额外非成分股。
- 股票日线和字段说明从原目录直接迁入，前后 SHA-256 核验，原路径不留副本；记录在同日 stock-migration.json。原始快照只读。
- 沿用 cutoff_v1 的时段归属与逐源行记录。每个交易日 16:00；仅 interval_end <= cutoff，真实历史发布/修订未验证。成员在源 Date 与预测日各有约束，跨调整日窗口仍可能不完整。
- 股票按指数实际交易日历重新索引；不把“该股票下一条记录”当下一交易日。标签为 Adjprcnd（不含现金红利再投资的可比收盘）在第 1/5 个市场交易日严格上涨，收平为 0。起点和终点需有价格且当日成交量>0；期间停牌不前填，价格/特征缺失保留；记录缺失标签。此为复权价格方向，不等同原始名义收盘方向。
- 行情不足20日、预测日起点无成交/缺失行情、指数特征缺失不入模；情绪缺失不删行、不填0，用训练集填补。新纳入公司情绪历史不足保留并显式控制。所有股票只在共同预测日期评估；公司数变化用每日等权评分处理。

## 三组共享逻辑回归

每期限独立模型，所有公司共享斜率，带训练期公司代码的正则化截距；未见公司用总体截距。固定 L2、C=0.01、阈值0.5、种子42，无选参/阈值搜索。训练权重为每天1/当日样本数，使一天总权重为1；数值缩放同样按该权重拟合，填补中位数只在训练集计算。

- A：股票1/5/20日收益、5/20日收益标准差、成交量相对自身过去20日、log(1+换手率%)、log(流通市值元)，加行业1/5/20日收益、20日波动率及覆盖/窗口/历史缺失控制。
- B=A+log(1+每观测小时帖量)、该强度相对自身此前20交易日均值的log差。
- C=B+净情绪(正−负)/总帖、当前净情绪减此前5交易日均值。暂不加入滞后候选、交互或更多算法。
- 换手率%=100×Dnshrtrd×Clsprc/(1000×Dsmvosd)。使用供应商现有成交口径，不额外累加盘后列，防止重复；与供应商正式换手率及盘后口径尚未另行交叉验证。
- A即含时段/小时覆盖、窗口小时、当前情绪缺失、热度历史缺失和方向历史缺失；让C−B更接近方向贡献，不能解释成因果效应。
- 指数也运行A/B/C，使用既有六个行情变量、同类覆盖与情绪公式；公司与指数目标、控制集不同，因此配对比较说明各自任务中的增量，不证明公司层面的因果机制更强。

## 冻结评价

配置 configs/company_pilot_v1.json。2025四季度为主要历史诊断；2026上半年两个季度为扩展诊断，既有市场期间已用于开发，不称全新测试。每季用此前全部历史且标签在训练截止已成熟；季度末未成熟评估标签也剔除。禁止随机拆公司日。

主指标：先在同日公司之间等权平均Brier，再对交易日等权。另报日期等权准确率、平衡准确率、训练期上涨频率参照、逐公司及逐季指标。标签重叠/行业共振由日期配对块bootstrap（季度内循环块长度10，4000次）描述不确定性；用97.5%双侧区间降低同时考察两个期限的偶然性，仍不宣称正式确证检验。

固定比较 A→B（关注度）、B→C（方向，核心）、A→C（总增量）。同时比较同一批日期上公司B→C与指数B→C的差值。主要2025与扩展2026分别展示，合并结果仅补充；不以挑选表现好的公司作为有效性依据。

本轮继续增加数据源的较强门槛（任一期限单独判断）：2025公司Brier方向增益至少0.001、97.5%区间下界>0、至少3/4季度为正；2026增益为正且2/2季度为正；公司相对指数的2025配对增益差区间下界>0。未达门槛不能宣称公司情绪更有用；如只B优于A而C不优于B，归为关注度线索。无论结果如何，本轮结束后不自动追加特征或模型搜索。
