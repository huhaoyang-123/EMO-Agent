# 任务六 评分前方案：冻结模型与新增日期影子预测（Issue #16）

日期：2026-11-25，执行人：成员 A（婺儒金）。本方案、configs/shadow_v1.json 在查看任何 2026-07-01 之后的预测结果之前提交。

## 为什么可以作为首轮前瞻检验
团队所有建模、选参和查看都截至 2026-06-30（baseline/stability/features/context）。2026-07-01 至 2026-10-09 的 931723、中证全指和成分股行情已在数据中，但从未用于建模或评价。本轮先冻结，再打分。
注意：这些日期的预测是在 2026-11-25 一次性批量生成的（retro_batch），不是当天实时生成；输入只用每个日期 15:00 及以前的收盘数据。之后的新日期用 shadow-predict 每天生成。

## 冻结内容
- 模型：prior（训练期上涨比例）、M（6 个行情变量）、MG（+3 个大盘变量）、MGB（+2 个广度变量）。情绪数据只到 2026-06-30，新增日期不评价情绪模型。
- 选 C：训练 ≤2025-12-31（标签成熟），验证 2026-01-01—2026-06-30，按 Brier 在 C_grid 中选择；之后在 ≤2026-06-30 的全部成熟样本上重新拟合并保存（joblib + SHA-256）。
- 预处理与模型族同 baseline（中位数填补 + 标准化 + L2 逻辑回归）。
- 特征：行情变量由 index_931723_full.csv 按 dataset.add_features 同样公式计算；大盘与广度变量用 context.py 的函数。重叠日期必须与 cutoff_v1 / context_v1 一致（测试检查）。

## 评价（2026-07-01—2026-10-09，同一批日期）
- 主指标 Brier；同时报告准确率、平衡准确率、校准（平均预测、实际上涨比例、ECE、斜率）。
- 比较：M 对 prior、MG 对 M、MGB 对 MG、MGB 对 prior；配对区块自助区间（长度 10，2000 次）。
- 约 70 个评价日，5 日标签重叠，只是首轮工程检查，不是证明有效的样本门槛（交接文档原话）。

## 判定
只描述，不再据此调参。若某模型 Brier 低于 prior 且区间不含 0，记为“首轮有正向迹象”，否则“首轮未发现优于参照”。

## 每日流程（Agent 雏形）
- `emo-agent shadow-predict --date YYYY-MM-DD`：读取冻结模型，计算当日特征，追加到 outputs/shadow_v1/shadow_log.csv，记录生成时间、输入文件哈希、模型哈希、缺失标志；同一日期不重复写入。
- `emo-agent shadow-evaluate`：对标签已成熟的日期打分。
